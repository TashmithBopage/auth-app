# 🔐 Auth App — Full Stack Authentication System

A full-stack authentication system built with React, Spring Boot, and MySQL.
Users can register and log in securely with passwords encrypted using BCrypt.

---

## 🛠️ Tech Stack

| Layer | Technology |
|-------|-----------|
| Frontend | React (Vite), React Router, Axios |
| Backend | Spring Boot, Spring Security, Spring Data JPA |
| Database | MySQL |
| Security | BCrypt Password Encoding |

---

## ✨ Features

- ✅ User Registration (Signup)
- ✅ User Login
- ✅ Password encryption with BCrypt
- ✅ REST API with Spring Boot
- ✅ MySQL database integration
- ✅ CORS configured for local development
- ✅ Auto table creation with Hibernate JPA

---

## 🚀 Getting Started

### Prerequisites
- Node.js
- Java 17
- MySQL 8.0

### Run the Backend
```bash
cd backend/backend
./mvnw spring-boot:run
```

### Run the Frontend
```bash
cd frontend
npm install
npm run dev
```

### Access the App
- Frontend → http://localhost:5173
- Backend API → http://localhost:8080
